# Worst Superpower

An entry for the make.fun bounty **Worst Superpower** (`u-suroto-worst-superpower-461dcdbe`).

`main.ts` writes a single one-line entry (at most 140 characters) to `/output/entry.txt`, inventing the most useless superpower imaginable:

> I can teleport anything I own exactly three centimetres to the left — once per object, forever, no take-backs.

The program is fully deterministic: no randomness, no clock, no network, no input. It always writes the exact same line.

## Run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set).
